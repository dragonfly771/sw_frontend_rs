Changelog
=
Branch stefly/vario-display (0.4.1.4 - 0.4.1.54, V2 display only, based on upstream master f947d5f), a summary. Status: test firmware, host
tests pass (cargo test), not reviewed by the Larus developers.

0.4.1.54: on top of the current upstream master
- Rebased on upstream master f947d5f: QNH on the CAN bus in Pa (#193), ballast fraction without a tank
  (#185), NaN and subnormal values from the EEPROM ignored, renamed polars, ASH 31 Mi polar.
- The flap placeholder follows the renamed AS 33 polars. cargo fmt applied. No functional change otherwise.

0.4.1.53: two-seater
- Two displays on one CAN bus share the glider settings (glider, masses, polar, flap table, cruise switch,
  gust filter, POT bar, volumes); brightness and pages stay per display. CAN config ids 0x1000 + PersistenceId
  (0x1FFF hello, 0x1FFE gear alarm), ignored by older displays and the sensor box. The gear alarm of the
  display with the switches shows and is acknowledged on both. Not tested in a two-seater yet.
- Centering page: large centering aid while circling, the track of the first 1.5 circles, standard info
  boxes in straight flight; thermal data recorded whatever page is shown.
- No flap tape while circling; POT yes / no symbol can be switched off; NO SENSOR BOX message can be
  acknowledged.
- Fix: black display after start (stack overflow into the statics) - smaller FLARM target table without the
  feature "flarm", smaller track buffer, size tests.

0.4.1.52: simple operation
- Usage mode Basic / Expert / Club, setup wizard (six questions), presets for vario response and sound,
  "Back" as the first row of every list.

0.4.1.51: thermal average box, help texts
- New info box Thermal Average; simpler average menu; one or two lines of help below every setup value;
  sound preview.

0.4.1.50: no NaN on the CAN bus
- The water ballast fraction is always 0 .. 1. A non-number sent by the display made sensor boxes 0.7.x / 0.8.x
  restart about every 35 s.

0.4.1.49: exact square root
- The no_std approximation of sqrt was up to 6 % too large; polar, density and speed to fly use an exact square
  root now. POT yes / no as a disc symbol.

0.4.1.48: POT box, new calculation
- "Potential Climb": what a circle here is worth, in every phase of flight, with a yes / no against the
  MacCready value. Fixture tests on pieces of real flights (tests/pot_climb.rs).

0.4.1.45 - 0.4.1.47
- GNSS menu with plain antenna names and the LARUS product (Essential / Competition / Competition Pro);
  pitot offset measurement back in the setup; battery voltage smoothed; larger flight menu; value font fixes.

0.4.1.37 - 0.4.1.44: page layout, menus, fonts
- Pages are set up on the page itself (Page Layout). Menus unified (header cap, value bar, no progress arcs).
  Fonts B612 and Barlow (SIL Open Font License, generated by tools/fontgen). Flap stages set up like on the
  glider. Large 2.76" display mounted upright. CLUT colour fix. Serial NMEA port with XCSoar or LXNAV protocol.

0.4.1.34 - 0.4.1.36: FLARM, canopy flasher, flaps, second display variant
- FLARM warnings and radar page (parked behind the crate feature "flarm"), SteFly canopy flasher output, flap
  table with sensor and recommended stage, name entry, ring design P1. Program fits into the flash again.
- Second display variant "large" (2.76" IPS) with its own hardware version; pack.py refuses an image whose
  code and header disagree.

0.4.1.33: setup menu regrouped
- Setup by topic, sensor box values at their function, Level Flight with automatic Calc Orientation.

0.4.1.26 - 0.4.1.32: ring page and centering aids
- 360 degree ring vario page as the only design, light outer ring per page, freely configurable pages
  (big encoder switches pages), spider assistant with action arcs, POT box, needle entry correction,
  VSYNC rendering, sensor box settings with save and restart dialogs.

0.4.1.4 - 0.4.1.21: tone, menus, gust filter
- Vario tone profile with new waveform and attack envelope, DAC driver fix; ring menus and editors for flight
  and setup; display dimming; gust filter for needle and tone (PT2 cascade and soft knee); auto switch to speed
  to fly at a set speed; sink tone off.
- Removed: V1 display, Air Avionics display and their asset sizes (this branch builds the V2 only).
